# Third-party content: BodyParts3D

`body-systems-3d.html` embeds 3D organ models from **BodyParts3D**.

Please also cite: Mitsuhashi N, et al. *BodyParts3D: 3D structure database for
anatomical concepts.* Nucleic Acids Res. 2009;37:D782-5. https://doi.org/10.1093/nar/gkn613

## Modifications made
- Models were taken from the BodyParts3D 3.0 release (via an STL mirror) for the
  liver, stomach, pancreas, gallbladder, esophagus, small and large intestine,
  rectum, heart wall, coronary and great vessels, lungs and bronchi, trachea,
  diaphragm, ribs and sternum, kidneys, ureters, bladder, urethra and renal vessels.
- Each model was mesh-simplified, converted to a common coordinate system,
  quantised, compressed and embedded as base64 in the HTML file.
- Colours, materials, animation and labels were added by this project.

Because the licence is Share-Alike, the embedded model data and any derivative
of it must be shared under the same licence (CC BY-SA 2.1 Japan or compatible).
The surrounding page code is the project's own.
